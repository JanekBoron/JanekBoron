### ⭐ Featured project

#### [Clash Zone](https://github.com/JanekBoron/ClashZone): e-sports tournament platform

My engineering thesis: a web platform for organizing e-sports tournaments and seasonal leagues for Counter-Strike 2 and League of Legends.

- **ASP.NET Core MVC (.NET 9)**, **EF Core 9**, **SQL Server**, ASP.NET Core Identity with Player / Organizer / Admin roles
- Refactored from a layered design into **hexagonal architecture** (ports and adapters), so the domain core does not depend on EF Core or external services
- **Riot Games API** integration (Account-V1, Match-V5) through a typed `HttpClient` with retry on HTTP 429
- **Stripe Checkout** for premium subscriptions, an in-app currency wallet and shop, email notifications over SMTP
- Automatic single-elimination brackets (with BYEs), match statistics and player rankings
- Tested with **xUnit**, **Moq**, EF Core InMemory and **Playwright** E2E tests; runs in **Docker** with docker-compose
